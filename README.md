**`Desenvolvedor FullStack`**

Busco uma oportunidade em que possa aplicar meus conhecimentos, adquirir experiência prática e continuar evoluindo profissionalmente. Tenho facilidade para aprender, gosto de resolver problemas e estou disposto a contribuir com a equipe enquanto desenvolvo minhas habilidades na área de tecnologia.
